# Interface

## Page d'accueil

À `/` : la page `index.md`, telle que
/operations/construire-le-site/generee la rend.

Affiche :
- [titre] le titre du navigateur `La Fabrique` ;
- [titre-principal] le titre `Bonjour le monde` ;
- [bienvenue] la ligne
  `Bienvenue à La Fabrique, atelier partagé à Strasbourg.` ;
- [lien-metallerie] un lien `La métallerie` vers `/ateliers/metallerie`.

## Page métallerie

À `/ateliers/metallerie` : la page `ateliers/metallerie.md`, telle que
/operations/construire-le-site/generee la rend. Les formulations sont
libres, sauf les textes entre accents graves.

Affiche, dans cet ordre :
- [titre] le titre du navigateur `L'atelier métallerie - La Fabrique` ;
- [titre-principal] le titre `La métallerie` ;
- [presentation] une présentation de l'atelier en deux ou trois
  phrases : la métallerie occupe la travée T1 ;
- [espaces] les espaces de la travée, dans l'ordre où on les
  rencontre : la mécanique vélo, la soudure, la chaudronnerie, un espace
  généraliste avec des plans de travail, l'usinage métal ;
- [usinage] l'usinage métal (tour, fraiseuse, perceuse-fraiseuse à
  colonne) n'est pas encore ouvert : des bénévoles le finalisent ;
- [materiel] le matériel, en liste : l'électroportatif courant
  (meuleuse, visseuse), la perceuse à colonne, les postes à souder
  (électrode enrobée, TIG, semi-automatique), la scie circulaire à
  métaux à lubrification, la scie à ruban pour métaux, la table de
  soudage, la plieuse, la rouleuse à tôle, les établis et les étaux ;
- [portes-ouvertes] l'invitation à venir visiter l'atelier un jeudi
  soir à 19 h, pendant les portes ouvertes ;
- [initiation] le parcours de l'usager : une initiation au soudage à
  l'électrode enrobée, puis un parcours selon le besoin (initiation au
  soudage TIG, initiation au soudage semi-automatique, accompagnement
  d'un projet), puis l'autonomie ;
- [reservation] les initiations ont lieu deux fois par mois, un
  vendredi et un samedi après-midi, et se réservent sur l'agenda ; la
  page ne donne pas de lien vers l'agenda ;
- [benevolat] les façons d'aider : venir un jeudi soir, venir à la
  réunion mensuelle du conseil d'administration, écrire à
  `contact@lafab.org` ;
- [contact] `contact@lafab.org` est un lien `mailto:`.
